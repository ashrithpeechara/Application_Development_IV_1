# C-ASA NOC Frontend (Next.js 14 + TypeScript)

This directory contains the Next.js 14 web application featuring dynamic OpenFlow SVG canvas visualizers, multi-agent status decks, and the AI Prompt-to-Node provisioning console.

## 🛠️ Tech Stack
- Next.js 14 (App Router)
- React 18
- TypeScript
- SCSS Modules (Cyber-NOC Theme)
- Lucide React Icons

## 🚀 Running Locally
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
